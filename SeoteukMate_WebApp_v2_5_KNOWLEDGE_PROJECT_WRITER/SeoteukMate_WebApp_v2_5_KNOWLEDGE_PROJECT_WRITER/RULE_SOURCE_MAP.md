# v2.3 사전 규칙 자료맵

v2.3은 업로드된 자료 전체를 앱 안에 복제하지 않고, 반복해서 나타나는 **탐구 설계·세특 기록 원칙을 규칙으로 압축**했습니다. PDF 원문은 사용자가 `지식 & 코디 → PDF Knowledge Vault`에서 직접 첨부해 필요한 페이지를 색인합니다.

## 공통 규칙에 반영한 구조
- 교과 세특은 결과보다 수업 중 관찰된 과정·태도·성장과 구체적 행동을 중심으로 기록
- 탐구주제는 교과에서 배운 내용과 학생의 궁금증에서 출발
- 주제 선정 시 흥미/진로 관련성, 난이도, 독창성, 시간, 자료 수집 가능성, 모둠 수행 가능성 고려
- 탐구 수행은 주제 선정 → 계획 → 자료/근거 수집 및 실행 → 산출물/발표 → 평가·성찰의 흐름
- 산출물은 보고서뿐 아니라 포스터, 에세이, 신문/뉴스, 웹사이트, 지도, 발표, 토론 등 교과에 맞게 다양화
- 추천도서는 탐구 아이디어·개념 확장용이며, 실제 독서 사실과 구분

## 계열/교과 규칙 출처

- 공학/정보: `교과세특 탐구주제 바이블(공학)`, `교과세특 추천도서 공학계열`

## PDF Knowledge Vault 사용 원칙
1. PDF의 텍스트는 **참고 지식**이다.
2. 참고 지식을 학생이 실제 수행·독서한 사실로 자동 변환하지 않는다.
3. 세특 생성 시 실제 관찰 입력과 명시적으로 연결되는 지식만 활용한다.
4. 지식 생성(탐구 아이디어)은 PDF 파일명·페이지를 출처 표기로 유지한다.
5. 대용량 PDF는 필요한 장부터 색인한다.
