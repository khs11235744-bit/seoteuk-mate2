# Seoteuk Mate v2.5 — KNOWLEDGE + PROJECT + SUBJECT WRITER

## 이번 버전의 핵심

### 1) 기본 지식팩 내장
사용자가 제공한 교과세특 탐구주제 바이블·추천도서·2026 학교생활기록부 자료를 페이지 단위로 미리 색인했습니다.

- 총 검색 청크: 3,426개
- 자료 메타데이터: 13개
- `default-knowledge-pack.js`에 내장되어 PDF를 매번 다시 첨부하지 않아도 검색 가능
- 기존 PDF Knowledge Vault는 그대로 유지되어 새 자료를 추가 색인할 수도 있음
- 지식팩의 책/논문/탐구사례는 **학생이 실제 수행한 사실로 자동 사용하지 않음**

### 2) 학생별 탐구 프로젝트 카드
헤더의 `📁 프로젝트`에서 학생별 탐구를 저장하고 이어서 작업할 수 있습니다.

저장 항목:
- 학번·이름
- 과목·희망진로
- 탐구 제목·질문
- 성취기준/수업목표
- 실제 수업활동
- 교사 직접 관찰
- 학생 산출물
- 실제 사용 사료·자료
- 학생 역할
- 피드백·변화·성장
- Knowledge Vault에서 만든 아이디어
- 참고한 지식팩의 파일명·페이지
- 진행 상태

Google/Firebase 클라우드가 연결된 경우 프로젝트 카드도 앱 상태와 함께 동기화 대상으로 포함됩니다.

### 3) 교과별 전용 작성기
헤더의 `🧭 교과 작성기`에서 세특을 구조적으로 작성합니다.

작성 흐름:
1. 과목 선택
2. 성취기준/수업목표 선택 또는 입력
3. 실제 수업활동
4. 교사 직접 관찰
5. 학생 산출물
6. 실제 사용한 사료·자료
7. 학생의 실제 역할
8. 피드백·수정·성장
9. 질문/후속 탐구
10. 근거 충족도 검사
11. AI/Antigravity 초안 생성
12. 2026 공식점검 후 교사 윤문

### 4) 한국사 성취기준 선택
사용자가 제공한 `교과세특 탐구주제 바이블(사회)_OCR_압축.pdf`에서 확인된 2022 개정 한국사 1·2 성취기준 25개를 정리해 선택 메뉴로 탑재했습니다.

자료에 없는 기준을 새로 만들어 넣지 않았습니다. 다른 과목은 현재 직접 입력 방식이며, 이후 동일한 방식으로 기준 라이브러리를 확장할 수 있습니다.

### 5) 생성 전 '근거 충족도' 검사
세특 생성 전에 앱이 다음을 분리합니다.

- `✓ 현재 쓸 수 있는 것`
- `△ 근거 부족 / 추가 확인`

예를 들어 역사 과목에서 실제 사용 사료가 비어 있으면, 특정 사료명을 AI가 새로 만들지 못하도록 경고합니다.

### 6) 기존 빠른 생성도 기본 지식팩 사용
왼쪽 `AI 생성` 입력창도 이제 다음을 함께 사용합니다.

- 2026 공식 잠금 규칙
- 교과별 사전 규칙
- 기본 지식팩 검색 결과
- 사용자가 추가로 색인한 PDF 지식
- 실제 교사 관찰 입력

단, 참고지식은 학생 사실과 분리합니다.

## 주의
- 기본 지식팩은 약 12MB이므로 첫 로딩이 일반 HTML보다 조금 더 걸릴 수 있습니다.
- 2026 학교생활기록부 자료는 생성문보다 상위의 '잠금 규칙'으로 적용합니다.
- AI/Antigravity가 생성한 결과는 그대로 학생부에 입력하는 용도가 아니라 교사 윤문 보조용 초안입니다.
